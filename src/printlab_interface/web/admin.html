新建计划（创建后默认是关闭的）

会调用模型的计划必须同时设置运行次数上限和 token 上限。上限在两次运行之间检查，已开始的一次运行不会被切断，所以最后一次可能超出 token 上限（实测一次带工具的运行约 6000 token）。

信箱

角色与工作流（只读）

它们是 config/agents/*.md 与 config/workflows/*.yaml 里的文件。这里不能编辑：改文件后重启服务。无效的定义会列出原因，并且没有任何工具权限。
